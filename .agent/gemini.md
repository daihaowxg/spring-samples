# 项目开发全局规范 (Agent Instructions)

本文件定义了 AI 助手在本项目协作中必须遵守的核心规则。

---

## 🌎 1. 语言与交互规范
- **交流语言**：始终使用 **中文** 进行对话和技术解释。
- **互动逻辑**：在执行实质性操作（如修改文件、运行命令、删除文件）之前，**必须先通过对话回答用户的问题并确认方案**。严禁在没有沟通的情况下直接执行任务。
- **文件命名**：所有文档的文件名必须采用 **中文**。

## 📂 2. 目录结构约定
- **文档归档**：所有手动创建的、面向用户的文档（如使用手册、架构说明等）应存放在项目根目录下的 `docs/` 文件夹中。

## ✍️ 3. Markdown 渲染规范
- **加粗与引号冲突处理**：
  - **规则**：严禁在加粗语法 `**` 内部直接包裹中文引号 `“ ”`（例如：❌ `**“示例”**`）。
  - **原因**：部分 Markdown 渲染引擎（如 VS Code 预览或某些 Git 平台）处理 CJK 字符与加粗符号边界时会失效。
  - **建议**：直接使用 `**示例**` 或将引号移到加粗符号外层 `“**示例**”`。

## 🛠️ 4. 技术实现约定
- **资源访问 (JDK)**：优先使用 `java.net.URI` 进行路径解析，随后通过 `uri.toURL()` 转换为 `URL`。
- **字符编码**：所有涉及到资源读取的 IO 操作，必须显式指定 `StandardCharsets.UTF_8` 编码。
