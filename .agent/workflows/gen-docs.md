# 自动生成文档 Workflow

## 执行步骤

### 1. 定位模块 `docs` 目录
分析当前活跃文件，定位其所属模块根目录下的 `docs` 文件夹。

### 2. 获取下一个文档序号
// turbo
```bash
# 获取当前 docs 目录下以数字和“、”开头的最大序号
# 请在实际执行时替换 <DOCS_PATH>
ls -1 <DOCS_PATH> 2>/dev/null | grep -E '^[0-9]+' | cut -d'、' -f1 | sort -n | tail -n 1
```
依据上述结果：
- 若结果为空，序号设为 `1`。
- 若有结果，序号设为 `最大值 + 1`。

### 3. 智能分析与生成内容
基于用户的输入（如一段代码、一个 URL 或一段对话总结），产出以下内容：
1. **中文标题**：精炼、直观（例如：Spring 资源加载机制）。
2. **文档正文**：
   - 包含必要的 Markdown 结构（标题、列表、代码块）。
   - 保持简洁，不使用过度复杂的预设。
3. **文件名**：格式为 `<序号>、<中文标题>.md`。

### 4. 应用文档模板
生成的 Markdown 必须包含以下页眉：
```markdown
# [中文标题]

> 最后更新时间：YYYY-MM-DD (使用当前日期)

[正文内容]
```

### 5. 展示并询问确认
在写入文件前，告知用户拟定的文件名和内容概览，询问是否直接生成。

---

## 注意事项
- 默认放在**当前正在编辑的模块**下的 `docs` 目录。
- 文档名称必须是**中文**。
- 序号后面紧跟中文顿号 `、`。
