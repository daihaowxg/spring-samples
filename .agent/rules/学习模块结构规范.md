# 学习模块结构规范

本规范适用于本项目中所有**技术学习/阅读类**模块，旨在通过统一、递进的项目结构，降低学习成本，提升代码可读性。

---

## 1. 模块与包结构

### 1.1 模块命名 (Module/Folder)

模块名**推荐使用数字前缀**，以指引整体阅读顺序，格式为：`<NN>-<模块名>` (中划线分割)。

```
<项目根目录>/
├── 01-spring-resource/      # 模块一级：数字-名称
├── 02-spring-ioc/
└── ...
```

### 1.2 基础包命名 (Base Package)

基础包名应由模块名映射而来，遵循 Java 命名规范：
- 将 `-` 替换为 `_`。
- **强制使用 `_` 作为数字前缀的保护符**（Java 包名不能以数字开头）。

格式：`io.github.daihaowxg._NN_<模块名>`

```
// 模块 01-spring-resource 对应的基础包
package io.github.daihaowxg._01_spring_resource;
```

### 1.3 子包结构 (Sub-package)

包结构按**学习路径**划分，同样使用 `_NN_` 前缀：

```
io.github.daihaowxg._01_spring_resource._01_jdk_basics;
io.github.daihaowxg._01_spring_resource._02_resource_interface;
```

> **总结**：文件系统用 `-`，Java 包名统一用 `_NN_` 风格。

## 2. 类命名规范

| 规则 | 说明 | 示例 |
|------|------|------|
| 统一后缀 | 演示类使用 `Demo` 后缀 | `FileDemo`, `ResourceLoaderDemo` |
| 概念优先 | 类名直接反映核心概念 | `ClassPathResourceDemo`（非 `SpringClassPathResourceDemo`） |
| 无冗余前缀 | 包名已表明上下文，类名不重复 | `_01_jdk_basics/FileDemo`（非 `JdkFileDemo`） |

## 3. 代码结构

### 3.1 基础演示类

```java
/**
 * <简要说明>
 * <p>
 * <详细说明>
 */
public class XxxDemo {

    public static void main(String[] args) {
        // 直接执行，无中间方法层
        System.out.println("=== Xxx 演示 ===");
        
        // 调用私有辅助方法
        demo1();
        demo2();
    }
    
    private static void demo1() { ... }
    private static void demo2() { ... }
}
```

### 3.2 Spring 容器演示类（推荐结构）

```java
/**
 * <简要说明>
 */
public class XxxDemo {

    // 1. 静态内部配置类（最前面）
    @Configuration
    @ComponentScan("...")
    static class Config {
        // Bean 定义
    }

    // 2. main 方法（紧随配置类）
    public static void main(String[] args) {
        try (AnnotationConfigApplicationContext context = 
                new AnnotationConfigApplicationContext(Config.class)) {
            // 演示逻辑
        }
    }
    
    // 3. 其他辅助方法（在 main 之后）
    private static void helper() { ... }
}
```

### 3.3 关键要求

- 每个 Demo 有独立 `main` 方法，可单独运行
- 有 Javadoc 说明类的用途
- 辅助方法使用 `private static`

## 4. package-info.java

每个包需要 `package-info.java`，**核心目的：指引阅读顺序**。

### 简化模板

```java
/**
 * 第 N 阶段：<阶段名称>
 * <p>
 * 阅读顺序：
 * <ol>
 *   <li>{@link XxxDemo} - 一句话说明</li>
 *   <li>{@link YyyDemo} - 一句话说明</li>
 * </ol>
 *
 * @see io.github.daihaowxg.<module>._NN_<prev_package>
 * @see io.github.daihaowxg.<module>._NN_<next_package>
 */
package io.github.daihaowxg._NN_<module>._NN_<package>;
```

## 5. 文档结构

文档目录与代码包结构对应：

```
docs/<NN>-<模块名>/
├── 01-<基础概念>.md
├── 02-<核心接口>.md
├── 03-<进阶用法>.md
└── ...
```

- 使用两位数字前缀
- 中文文件名
- 与代码包大致对应

---

## 6. 验证清单

创建或重构模块时，**必须确认**：

- [ ] 包结构按学习路径划分，使用 `_NN_` 前缀
- [ ] 类名使用 `Demo` 后缀，概念优先
- [ ] 每个 Demo 可独立运行（有 main 方法）
- [ ] 每个包有 package-info.java（含阅读顺序）
- [ ] 文档目录与代码结构对应
- [ ] **`mvn compile` 编译通过**（必须）
