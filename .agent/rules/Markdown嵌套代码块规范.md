# Markdown 嵌套代码块规范

## 规则

当需要在代码块内展示其他代码块时，**外层必须使用更多的反引号**包裹。

## 原理

Markdown 解析器使用**贪婪匹配**：
- 遇到 ` ``` ` 开始代码块后，会向下扫描找**第一个** ≥3 个反引号的行作为结束
- 如果外层和内层都用 3 个反引号，内层的 ` ``` ` 会被当作外层的闭合标签

## 正确示例

`````markdown
````markdown
这是外层代码块
```java
// 这是内层代码块
public class Demo {}
```
外层继续...
````
`````

## 错误示例

```markdown
```markdown    ← 开始
```java       ← 解析器认为这里就闭合了！
...
```           ← 导致渲染错乱
```

## 适用场景

- 在 workflow 或文档模板中展示代码块示例
- 技术文档中演示 Markdown 语法
- 任何需要"代码块套代码块"的场景
